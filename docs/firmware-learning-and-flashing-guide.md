## 🎯 導言與核心思維

在工業自動化與起重機（天車）控制中，「無線遙控器」不同於一般消費級遙控器（如冷氣或電視遙控器）。工業場景首重**絕對安全（Safety First）**與**零誤動作**。

本筆記彙整從「純軟體虛擬機操作」到「實體硬體燒錄」與「工廠量產維護」的完整技術學習路線，讓初學者能以系統化、循序漸進的方式建立完整的嵌入式韌體工程知識。

### 第一階段：純軟體與虛擬機模擬期（目前階段）

在還沒有買任何零件之前，先在電腦上建立「數位分身 / 軟體在環（SITL）」，將狀態機邏輯、封包格式與防呆機制徹底驗證。

* **核心練習工作台**：
  1. **Web 虛擬機操作台 (`simulator/index.html`)**：
     - 在本機瀏覽器中隨時開啟，體驗工業黃黑高防護防摔外殼 HMI。
     - **急停拍下卡死（E-STOP Lock）**：拍下紅色蘑菇頭按鈕，所有動作通道強制歸零，系統進入安全切斷模式；旋轉復歸後，必須按 START 才能重新就緒。
     - **對向動作互鎖（Interlock Protection）**：同時按住 `UP + DOWN`，系統自動辨識為衝突並發出 `INTERLOCK ERROR`，防呆全斷。
     - **2.4GHz RF 封包 Hex 監聽**：即時觀察發射的 15-byte 緊密二進位封包與 CRC16 校驗碼。
  2. **Wokwi 電路模擬器 (`diagram.json`)**：
     - 在 VS Code 內模擬虛擬 ESP32 開發板 + SSD1306 OLED 螢幕，直接跑真實 C/C++ 二進位韌體檔。
* **重點學習觀念**：
  - 非阻塞式輪詢（`millis()` 計時器，避免使用 `delay()` 卡死系統）。
  - 按鍵防彈跳濾波（Debounce 20ms）。
  - 失效保護與心跳包（Watchdog Fail-Safe：每 100ms 傳送心跳，超時 500ms 接收端自動跳脫）。

### 第二階段：實體硬體初體驗（個人實驗室/麵包板期）

當您準備好進入實體世界時，只需花費約台幣 150~250 元，即可完成實體燒錄體驗。

#### 1. 採購建議清單
| 零件名稱 | 建議型號 / 規格 | 預估費用 | 用途說明 |
| :--- | :--- | :--- | :--- |
| **主控開發板** | ESP32 NodeMCU / DevKit V1 (30-pin 或 38-pin) | 約 NT$ 120 | 內建 Wi-Fi/BLE/ESP-NOW，具 Micro-USB 或 Type-C 介面 |
| **顯示螢幕** | 0.96 吋 I2C OLED (SSD1306 128x64, 四腳位) | 約 NT$ 50 | 顯示動作方向、電量、發送封包序號 |
| **按鍵與線材** | 輕觸微動開關 × 4~8 顆、杜邦線、麵包板 | 約 NT$ 50 | 模擬操作按鈕與接線 |
| **USB 傳輸線** | Micro-USB 或 Type-C 資料線 | 自備 / 現成 | **注意：必須具備資料傳輸功能（非純充電線）** |

#### 2. 實體燒錄四步法（Flashing 實務）
* **步驟 1：硬體連接**
  - 將 ESP32 透過 USB 線接上 Mac / PC。
* **步驟 2：辨識連接埠**
  - 在 Mac 終端機執行 `ls /dev/cu.usb*` 或 `pio device list`，會看到類似 `/dev/cu.usbserial-0001` 的裝置名稱。
* **步驟 3：一鍵燒錄**
  - 在專案目錄下執行：`pio run -t upload`。
  - 亦可直接在 VS Code 底部工具列點擊 `→`（PlatformIO Upload）圖示。
* **步驟 4：避坑密技（手動進入下載模式）**
  - 若終端機卡在 `Connecting........_____.....` 甚至逾時報錯，請按住板子上的 **BOOT 鍵**，點按一下 **EN/RST 鍵**放開，電腦偵測到進入 Bootloader 後即可放開 BOOT 鍵順利寫入。

#### 步驟 3：開啟序列埠監視器（Serial Monitor）
燒錄成功後，晶片會自動重啟執行，執行下列指令監看實體運作狀態：
```bash
pio run -t upload -t monitor
```
按下實體按鈕，終端機即時跳出：
```text
[PKT #1] Type:0x01 State:0 Mask:0x0000 CRC:0x4FA2
```

### 第三階段：邁向工業量產與現場維護（進階工程思維）

當原型機驗證成功，準備裝入手持外殼走向實際應用時：

#### 1. OTA (Over-The-Air) 空中升級
- **問題痛點**：工業遙控器為了達到 **IP65 防水防塵**，外殼內側具備厚實橡膠密封圈並鎖上多顆螺絲，售後維護若要插 USB 線拆裝極不切實際。
- **解法**：在韌體中開啟 OTA 機制，讓遙控器透過無線 Wi-Fi 或專用對頻模式，直接將新版二進位韌體推入 Flash 晶片更新。

#### 2. 工廠生產線快速燒錄治具（Pogo Pin 頂針針床）
- **工廠生產標準**：PCB 電路板背面預留測試焊盤（Test Pads: 3V3, GND, TX, RX, IO0）。
- **流程**：操作員將裸板扣入氣動夾具，彈簧頂針直接接觸焊點，電腦自動化程式在 3 秒內完成「燒錄韌體 + 注入出廠唯一 MAC / 32-bit 安全金鑰 + RF 射頻功率校正」。

#### 3. 射頻安全防護機制
- **防重放攻擊（Anti-Replay Attack）**：每個封包內建 16-bit 滾動計數器，接收端若收到重複或倒退的序號立即拋棄。
- **32-bit 系統唯一配對碼（Unique System ID）**：確保同一廠房內數十台吊車同時作業時，絕不跨台串動。

## 🛠️ 實用工程指令速查 (Cheat Sheet)

### PlatformIO 常用指令
```bash
pio run                 # 編譯韌體
pio run -t upload       # 編譯並燒錄進實體板
pio device monitor      # 開啟序列埠監視器 (115200 baud)
pio run -t upload -t monitor # 編譯 + 燒錄 + 監聽一次完成
pio device list         # 列出已連接的硬體設備
```
